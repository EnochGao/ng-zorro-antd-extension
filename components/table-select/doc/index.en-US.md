Table select component. `nzx-table-select` and `nzx-page-table-select` (with pagination) export the `NzxAbstractTableSelect` abstract class by default, which can be extended to implement custom pagination.

## Support Version

<label type="success">v15.5.0+</label>

## When To Use

### Import

```ts
import { NzxTableSelectModule } from "ng-zorro-antd-extension/table-select";
```

See examples for detailed usage.
