Double-click or click a button to make the content area editable. The default type is unified (number, string). You can optionally use Typography from ng-zorro.

## Support Version

<label type="success">v15.10.0+</label>

## When To Use

### Import

```ts
import { NzxEditableModule } from "ng-zorro-antd-extension/editable";
```

### html

```html
<span nzx-editable [(nzxContent)]="item.country" [nzxShowBtn]="false"></span>
```
